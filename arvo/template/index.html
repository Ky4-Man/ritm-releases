Шаблон семейного бюджета

Записи на одном листе, итоги месяца на другом. Восемь групп расходов, лимиты, суммы считаются сами. Бесплатно и без регистрации.

Скачать шаблон (Excel)

Для Google Таблиц: создайте таблицу, затем Файл → Импортировать → Загрузить и выберите этот файл. Оформление там может быть проще, итоги считаются так же.

Как пользоваться

  1. На листе «Записи» удалите строки с примерами.
  2. Записывайте каждую трату и каждый доход новой строкой в день покупки.
  3. На листе «Месяц» поставьте лимиты на две-три группы, где деньги уходят незаметно.

Если таблицу не хочется открывать каждый день

Arvo — учёт денег, который не бросаешь: трата записывается за два касания, а куда уходят деньги, видно с одного взгляда. Без регистрации и рекламы, для Android.

Как перенести записи в Arvo

  1. Удалите примеры и сохраните файл. Из Google Таблиц: Файл → Скачать → Microsoft Excel (.xlsx).
  2. Передайте файл на телефон. В Arvo: Ещё → Экспорт → Выбрать файл.
  3. Нужна версия Arvo 0.13.7 или новее. Более старые версии читают только CSV: Файл → Сохранить как → тип «CSV UTF-8» на листе «Записи».
